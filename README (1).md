# The Descent Bridge 0.4.4.1
Install under Foundry User Data/Data/modules/the-descent-bridge and restart Foundry.
Use Configure Settings → Module Settings → The Descent Bridge → INITIALIZE FLOOR 1.
It creates/updates 10 managed blank Floor 1 scenes plus a reference journal. Re-running is designed not to duplicate managed scenes.
The bridge token is NOT your Foundry license key.
